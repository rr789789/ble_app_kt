## 项目概述
开发一个可以连接小米温湿度计2（Mi Temperature and Humidity Monitor 2 / LYWSD03MMC）的安卓手机应用。

## 需要澄清的问题

### 1. 技术栈选择
您希望使用哪种技术来开发这个应用？

- **选项A: Kotlin原生开发** - 推荐方案
  - 优点：性能最佳，BLE支持最完善，GitHub Actions编译配置简单
  - 缺点：仅支持Android

- **选项B: Flutter跨平台**
  - 优点：可同时支持Android和iOS
  - 缺点：BLE插件可能不够稳定

- **选项C: React Native**

  - 缺点：BLE支持相对较弱

## 小米温湿度2 设备信息

### 设备规格
- 型号: LYWSD03MMC
- 蓝牙: BLE 4.2
- 温度范围: -0.1°C ~ 60°C
- 湿度范围: 0% ~ 99% RH
- 电池: CR2032纽扣电池
- 存储: 可存储约100天数据（取决于记录间隔）

### 通信协议
- 使用BLE协议
- 需要绑定/加密才能读取数据
- 支持自定义固件（如PVVX固件）提供更多功能

### 开源参考
- [Bleak](https://github.com/hbldh/bleak) - Python BLE库
- [Xiaomi BLE Token](https://github.com/iskalchev/Xiaomi-BLE-Token) - 设备绑定
- [PVVX Firmware](https://github.com/pvvx/ZigbeeTLc) - 自定义固件
